# 蜡皮捏捏 · Cyber Wax Lab

沿用已有的 Three.js 程序化布丁、焦糖、奶油和樱桃造型，新增完整蜡层与局部揉捏交互。

## 使用

- 第一次点击甜点：出现以落点为中心的放射、分叉冰裂纹，蜡层仍完整贴附；松开后在同一区域再次点击，才碎开并轻轻脱落。按住不自动触发第二阶段。
- 按压已露出的布丁、焦糖、奶油或樱桃：轻按即产生宽阔圆润的凹痕；弹性部分轻柔回弹，塑性部分保留。
- 按住内芯拖动：抓住粘土向外拉长、向内推拢，拖出轮廓仍保持抓取。
- 揉成团：剥开剩余蜡层，把所有食材一起压拢成紧凑的一团。
- 音效：蜡皮为高频脆裂声，粘土为低频柔软揉压声；可随时静音。首次点击后启用。
- 空白处拖动：旋转查看；滚轮缩放。
- Wax Thickness：0.01–0.20，同时改变厚度、透明度、破裂范围和碎片冲量；任何厚度均为两次点击破碎。
- RESET：恢复几何、蜡片、相机和交互状态，不刷新页面，保留当前调节参数。

## 开发

安装依赖：`pnpm install --frozen-lockfile`。
启动：`pnpm dev`。构建：`pnpm build`。
数值验证：`node tests/simulation.mjs` 和 `node tests/assembly.mjs`。

## 实现

`src/deformation/ClayDeformer.js`：局部坐标下的平滑径向压陷，弹性/塑性位移分离，三轮局部位移场平滑、逐帧更新变形法线和有界拖拽。弹性柔和恢复，塑性压痕保留。

`src/wax/createEnvelope.js`：从整个甜点的水平截面提取外轮廓，生成单一封闭外壳，消除组件之间的内部蜡层。原模型不变。

`src/wax/WaxFractureSystem.js`：初始只绘制连续蜡壳。第一次点击时由 `IceCracks.js` 把放射分叉裂纹投影到完整蜡壳上；第二次点击才裁出不规则局部开口并生成碎片，碎片轻轻落下，不向外飞溅。

`src/interaction/PointerInteraction.js`：Pointer Events + Raycaster，只检查甜点对象，完整蜡区域阻挡内芯变形；支持取消、失焦和指针捕获。

## 验证与限制

生产构建与数值模拟测试通过；覆盖整体外壳闭合性、初始无碎片、光线命中、完整蜡阻挡、点击中心开口、局部破裂、200 毫秒轻按压痕、压痕持久性、全厚度两段点击与长按不误碎和精确重置。未做浏览器视觉或真实触摸设备测试。

使用外轮廓包络和局部径向断裂近似；蜡壳跨过组件接缝与细小凹槽，碎片没有彼此碰撞。所有食材均可塑形，邻近部分共享手势位移；揉团以共同的球形边界压缩。保留食材网格和颜色，不进行拓扑融合或颜色混合。并非完整软体或体积守恒模拟。
